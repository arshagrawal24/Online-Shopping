# Online-Shopping

A simple **Command Line Interface (CLI) Online Shopping System** built using Python.
This project simulates a basic online shopping experience where users can browse products, add items to a cart, and checkout.

---

## Features

*  View available products
*  Add items to the shopping cart
*  View cart with subtotal calculation
*  Checkout with tax calculation
*  Exit the application

The program runs entirely in the **terminal/command line**.

---

##  How It Works

The system uses:

* **Dictionary data structures** for the product catalog
* **Shopping cart dictionary** to track items and quantities
* **Functions** for modular program structure
* **User input handling** for menu navigation

Key components in the program include:

* Product catalog management
* Cart operations
* Checkout system with tax calculation
* Menu-driven interface


2. Navigate to the project folder


3. Run the program

